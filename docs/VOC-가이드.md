# VOC(의견 게시판) 운영 가이드

앱의 ✉ 버튼(또는 설정 → VOC 게시판)에서 사용자가 의견을 남기고, 운영자가 그대로 복사해 Claude에게 붙여넣으면 수정이 반영되는 구조입니다.

## 1. 사용자가 글 쓰는 방법
| 칸 | 내용 | 예시 |
|---|---|---|
| 분류 | 버그·오류 / 개선 요청 / 새 기능 / 불만 / 기타 | 버그·오류 |
| 제목 | 한 줄 요약 (80자 이내) | 일정 목록에서 완료 체크가 한 번에 안 돼요 |
| 어디서 | 화면과 버튼 이름 | 일정 목록 › 체크 원 |
| 지금 상황 | 눌렀을 때 실제로 어떻게 되는지 | 두 번 눌러야 체크가 됩니다 |
| 원하는 모습 | 어떻게 되면 좋은지 (선택) | 한 번 누르면 바로 완료 |
| 환경 | 기기·브라우저·앱 버전 | 자동 입력 |

자유게시판처럼 목록 · 글 보기 · 댓글 · 공감(♥)을 쓸 수 있고, 운영자가 처리 상태(접수 → 검토 중 → 반영 완료 / 보류)와 답변을 남깁니다.

## 2. 운영자 반영 절차
1. 목록에서 **접수 N건 모두 Claude용으로 복사**(또는 글 안의 *Claude용으로 복사*)를 누릅니다.
2. Claude 대화창에 **그대로 붙여넣기**합니다. 아래 형식으로 복사됩니다.

```
[VOC #A1B2 · 버그·오류]
제목: …
위치(화면): …
지금 상황: …
원하는 모습: …
환경: 아이폰 · 사파리 · 설치 앱 · v74
작성자: … · 공감 3

→ 위 VOC 내용대로 앱을 수정하고, 수정한 내용을 한 줄씩 알려 주세요.
```
3. 수정이 끝나면 해당 글의 상태를 **반영 완료**로 바꾸고 답변에 버전(예: v75 반영)을 적습니다.

## 3. 보안
- 글·댓글 읽기와 쓰기는 로그인한 사용자만 가능합니다.
- 본인 글만 수정·삭제할 수 있고, 처리 상태와 답변은 운영자만 바꿀 수 있습니다(서버에서 강제).
- 운영자 여부는 서버가 판단하며 앱 코드에 개인정보를 두지 않습니다.
