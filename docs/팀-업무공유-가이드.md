# 팀 업무 공유 · 인수인계 가이드

## 목적
부서 팀원의 업무를 서로 공유하고, 휴가·타 팀 발령·현장 발령으로 공백이 생기면 다른 팀원이 업무를 이어받습니다.

## 사용 순서
1. **팀장**: 👥 팀 업무 현황 → 팀 만들기 → 나온 **팀 코드**(8자리)를 팀원에게 전달
2. **팀원**: 로그인 → 팀 업무 현황 → 팀 코드로 가입
3. **일정 공개 범위**: 일정마다 `👥 공개` / `🔒 비공개` 버튼으로 선택 (분류별 자동 공개도 가능). 비공개 일정은 서버로 전송되지 않아 누구에게도 보이지 않음
4. **근무 상태**: 휴가·타 팀 발령·현장 발령과 기간·메모를 등록 (팀장은 팀원 상태도 등록 가능)
5. **회의 화면**: 팀장이 화면에 띄우면 팀원별 오늘 일정이 큰 글씨로 표시 (← → 로 날짜 이동, Esc 닫기, 1분마다 자동 갱신)
6. **인수인계**: 공백 중인 팀원의 `이어받기`를 누르면 앞으로의 공개 일정이 내 일정으로 복사되고(`[○○ 님 업무 인수]` 메모 포함), 팀 화면에 인수인계 이력이 남음

## 보이는 정보 / 보이지 않는 정보
- 보임: 공개한 일정의 제목 · 날짜 · 시간 · 분류 · 메모, 근무 상태
- 안 보임: 비공개 일정, 첨부 이미지, 다른 팀원의 설정

## 보안 (서버에서 강제)
- 같은 팀 구성원만 팀원의 공개 일정을 읽을 수 있음
- 자신의 일정은 본인만 수정 가능, 근무 상태는 본인과 팀장만 변경 가능
- 팀은 한 사람당 하나만 가입 가능
