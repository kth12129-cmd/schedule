# 업무 일정

달력 · 할 일 · 메모를 한 화면에서 다루고, 반복되는 업무 사이클의 진행 상황과 기한 위험을 함께 보여주는 일정 앱입니다.

PC·휴대폰·웹이 **하나의 앱**입니다. 계정으로 로그인하면 기기끼리 자동으로 맞춰집니다.

---

## 설치 순서

전체 30분 정도 걸립니다. 순서대로 따라오시면 됩니다.

### 1단계 · Supabase 프로젝트 만들기 (무료)

1. https://supabase.com 에 가입하고 **New project** 를 만듭니다.
   - Region은 `Northeast Asia (Seoul)` 을 고르세요. 응답이 빠릅니다.
   - Database Password는 따로 적어두세요. 앱에서 쓰지는 않지만 나중에 필요합니다.
2. 프로젝트 생성에 2~3분 걸립니다.

### 2단계 · 테이블 만들기

1. 왼쪽 메뉴 **SQL Editor** → **New query**
2. 이 폴더의 `supabase-setup.sql` 내용을 전부 붙여넣고 **Run**
3. `Success. No rows returned` 가 나오면 성공입니다.

### 3단계 · 이메일 확인 끄기 (선택, 권장)

1. **Authentication → Sign In / Providers → Email**
2. **Confirm email** 을 끕니다.

끄지 않으면 가입할 때마다 메일함에서 확인 링크를 눌러야 합니다. 혼자 쓰는 초기 단계에는 꺼두는 편이 편합니다. 나중에 다른 사람에게 열어줄 때 다시 켜세요.

### 4단계 · 주소와 키 복사

1. **Project Settings → API**
2. 두 값을 복사해 둡니다.
   - **Project URL** — `https://xxxxxxxx.supabase.co`
   - **anon public** 키 — `eyJ...` 로 시작하는 긴 문자열

> `service_role` 키는 절대 쓰지 마세요. 그 키는 모든 데이터에 접근할 수 있어서 웹페이지에 넣으면 안 됩니다. `anon public` 키는 공개되어도 안전합니다. 위 SQL의 보안 정책(RLS)이 각자 자기 데이터만 보게 막아 줍니다.

### 5단계 · 웹에 올리기 (GitHub Pages, 무료)

1. GitHub에서 저장소를 새로 만듭니다.
2. 이 폴더의 파일을 전부 업로드합니다.
   ```
   index.html
   manifest.json
   sw.js
   icons/
   ```
3. **Settings → Pages** → Source를 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)` 로 지정하고 저장.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소명>/` 이 열립니다.

Netlify나 Vercel에 폴더를 끌어다 놓아도 됩니다.

### 6단계 · 앱에서 연결하기

1. 위 주소를 엽니다.
2. 우측 상단 **⚙ → 계정 · 기기 연동 → 열기**
3. 4단계에서 복사한 **Project URL** 과 **anon key** 를 붙여넣고 **연결**
4. 이메일과 비밀번호로 **가입** → **로그인**
5. ⚙ 의 점이 초록색이 되고 "동기화됨"이 뜨면 끝입니다.

다른 기기에서도 같은 주소를 열고 3~4단계를 반복하면 됩니다. 한 번 입력하면 그 기기는 계속 기억합니다.

## 앱으로 설치하기

**맥북 / 윈도우 (Chrome, Edge)**
주소창 오른쪽 끝의 설치 아이콘(⊕ 또는 모니터 모양)을 누릅니다. 안 보이면 ⋮ 메뉴 → **앱 설치**. 독이나 작업표시줄에 아이콘이 생기고 브라우저 탭 없이 독립 창으로 열립니다.

**아이폰 (반드시 Safari)**
하단 **공유** → **홈 화면에 추가**. 홈 화면 아이콘으로 실행하면 주소창 없이 앱처럼 열립니다. 알림도 이렇게 설치한 뒤에만 동작합니다 (iOS 16.4 이상).

**안드로이드 (Chrome)**
설치 배너가 뜹니다. 없으면 ⋮ → **앱 설치**.

## 쓰는 법

| | |
|---|---|
| 일정 추가 | 아래 입력창에 `내일 3시 산포 기성 제출`. 날짜·시간을 알아서 분리합니다 |
| 중요 표시 | 앞에 `!` 를 붙이거나 항목의 ☆ 를 누릅니다. 맨 위로 올라갑니다 |
| 일정별 메모 | 항목의 ✎. 평소엔 접혀 있고 마우스를 올리면 펼쳐집니다 |
| 창 확대 | 달력·목록·메모 칸을 더블클릭. Esc 로 복귀 |
| 월 이동 | ← → 키, 트랙패드 좌우 스와이프, 달력 스와이프 |
| 연도 선택 | 상단의 연도를 누르면 목록이 펼쳐집니다 |
| 업무 사이클 | ◱ 에서 `가마지천 업무 사이클`, `2026년 가마지천 실적` 처럼 검색 |
| 단계 설정 | ◱ → 단계 설정. 이름·순서·기한 일수를 실제 업무에 맞게 고치세요 |

## 알아둘 점

- **백그라운드 알림은 되지 않습니다.** 설정한 시각 이후 앱을 열면 알림이 뜹니다. 며칠 열지 않으면 알림이 가지 않습니다. 진짜 푸시 알림에는 푸시 서버가 따로 필요합니다.
- **오프라인에서도 열리고 입력됩니다.** 기기에 쌓아뒀다가 연결되면 올립니다.
- **동시에 두 기기에서 같은 항목을 고치면** 나중에 고친 쪽이 남습니다.
- Supabase 무료 구간은 개인 사용에 충분하지만, **2주간 접속이 없으면 프로젝트가 일시 정지**됩니다. 대시보드에서 바로 재개할 수 있습니다.

## 직접 고치기

`index.html` 하나에 HTML·CSS·JavaScript가 전부 들어 있습니다. 빌드 도구가 없습니다.

| 위치 | 내용 |
|---|---|
| `DEFAULT_STAGES` | 업무 단계 기본값과 기한 일수 |
| `:root` CSS 변수 | 색상 |
| `.cal-pane` / `.list-pane` / `.memo-pane` 의 `flex` | 세 칸의 화면 비율 (기본 6 : 2.6 : 4) |
| `parseInput()` | 한 줄 입력의 날짜·시간 해석 규칙 |
